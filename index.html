Computer Vision

Drowsiness Detection System

Real-Time Driver Safety Monitoring System

Overview

Driver fatigue and microsleeps are leading causes of commercial and personal highway accidents. This system provides a non-intrusive, camera-based safety monitor that continuously analyzes ocular behavior in real time.

Technical Architecture

  • Facial Landmark Localization: Detects 68 facial landmark coordinates in real-time video frames using dlib / OpenCV.
  • Eye Aspect Ratio (EAR) Algorithm: Evaluates the geometric ratio of vertical eye landmark distances relative to horizontal eye width: EAR = (||p2 - p6|| + ||p3 - p5||) / (2 * ||p1 - p4||)
  • Adaptive Temporal Window: Implements a consecutive frame threshold filter to prevent false triggers from natural blinking while detecting genuine prolonged closures (> 1.5 seconds).
  • Audio-Visual Alert Engine: Integrates immediate acoustic alarms and visual screen flashes to alert the driver before accident risks escalate.

Key Results & Highlights

Real-Time FPS: 30+ Robust in Variable Lighting OpenCV & Python Driver Safety Use-Case
